# tech-zjf

全栈开发，主要使用 TypeScript / React / Next.js / Vue / Node.js。

关注前端体验、后端接口、工程化交付，以及 AI 应用在实际业务里的落地。

## 我会什么

- 前端开发：React、Next.js、Vue、组件封装、响应式页面、状态管理、数据请求。
- 后端开发：Node.js、接口设计、鉴权流程、数据建模、第三方服务接入。
- 全栈交付：后台系统、Dashboard、业务工具、从页面到接口的数据链路。
- 工程化：TypeScript、pnpm、Vite、Monorepo、代码规范、构建和维护。
- AI 应用：LLM API 接入、Prompt 工作流、内容处理、信息提取、自动化能力。
- 桌面和工具：Electron、快捷键交互、浏览器侧交互、小型效率工具。

## 技术栈

TypeScript, JavaScript, React, Next.js, Vue, Node.js, HTML, CSS, Tailwind CSS, Vite, Electron, pnpm, Git.

## 当前关注

- 更稳定、可维护的全栈 Web 应用。
- 后台系统和 Dashboard 的体验优化。
- AI 工作流、自动化和内容处理。
- 清晰的代码结构和长期可维护性。
